# INFINITE
🛡️ Infinite Pro is a Linux-first C++20/GTK4 security suite for privacy, monitoring, and defensive system analysis. It includes 🔐 encrypted local accounts, AES-256-GCM vault storage, 📊 live telemetry, 🧩 process inspection, 🌐 network diagnostics, 📡 Wi‑Fi/device monitoring, 🔍 report-only scanning, 🔑 SHA-256 hashing, 📝 protected history, and 🔒 session locking.
